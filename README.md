# Karnor frontend

React, TypeScript, Vite och Tailwind. Frontendkoden finns i `karnor-app`.

All backendlogik finns i det separata Kotlin/Spring-projektet `C:\Users\TaraR\IdeaProjects\KarNor`. Starta Spring på port 8080 och kör `npm run dev` här för frontend på `http://localhost:5173`. Frontendens Vite-proxy vidarebefordrar API-, media- och PDF-anrop till Spring.

Se [karnor-app/CMS.md](karnor-app/CMS.md) för konfiguration och drift.
